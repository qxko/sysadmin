
# Linux Basics — Day 1

## Commands I Learned

### 1. `whoami`
Shows the current username.

### 2. `uname -r`
Shows the Linux kernel version.

### 3. `df -h`
Shows disk space usage in a human-readable format.

### 4. `hostname`
Shows the computer's hostname.

### 5. `cat /etc/os-release`
Displays information about the operating system and its version.

### 6. `ip addr`
Displays network interfaces and IP addresses.

### 7. `ip route`
Displays the routing table and the default gateway.

### 8. `hostname -I`
Displays the computer's IP addresses.

### 9. `ping -c 4 1.1.1.1`
Tests network connectivity to an IP address by sending four packets.

### 10. `ping -c 4 google.com`
Tests network connectivity and DNS name resolution.

### 11. `ss -tuln`
Displays listening TCP and UDP ports.

### 12. `ss -ltn`
Displays listening TCP ports.

### 13. `systemctl status ssh.socket`
Shows the status of the SSH socket.

### 14. `sudo ufw status`
Checks whether the UFW firewall is active.
